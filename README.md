# 직무분석 실습
채용공고를 붙여넣으면 AI에 넣을 프롬프트를 만들어 주는 단일 페이지 웹앱 (index.html 하나로 동작).

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `job-analysis`, Public)
2. `index.html`, `README.md` 업로드 (Add file > Upload files)
3. Settings > Pages > Branch: `main` / `/ (root)` > Save
4. 1~2분 후 `https://<계정명>.github.io/job-analysis/` 로 접속
